Pick the book you just read

  • Monk Mode — A Monk Mode block is a fixed-length period with one declared output, a written list of what is suspended for its duration, and a defined end date that arrives whether or not the output is finished.
  • The Executive Dysfunction Field Manual — The Six-Function Check is a diagnostic-free routine for locating which part of getting something done has stalled — initiation, working memory, sequencing, time estimation, emotional regulation, or task switching — so the response can match the stall rather than the mood.
  • Task Paralysis — The Task Paralysis Exit Ramp is a five-step method for locating the exact moment action stops, reducing the decision surface, choosing one reversible action, setting a stop point, and preserving a restart path.
