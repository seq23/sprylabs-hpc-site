Canonical model library

  • Continuity Architecture - A simple way to keep progress alive when your mood, schedule, or motivation changes: do the smallest controlled action today, then continue tomorrow.
  • Reset Cycle Model - The common failure loop: clarity → motivation → strong start → missed day → avoidance → reset → new plan → repeat.
  • Operational Drift - The gap between what you intend and what your days actually execute-especially after interruptions.
  • Agenda-First Execution Loop - A daily sequence that turns “I should do…” into a concrete next action: Agenda → One Action → DONE → Review (no spirals).
  • Scope-Cap Rule - A hard limit on how much you do today so you don’t overcorrect and burn out.
  • Minimum Viable Day - A pre-defined “floor day” that counts as staying in the game: one controlled action, then stop.
  • Never Miss Twice Recovery - A recovery rule: after a miss, you resume at minimum scope the next day-no punishment, no backlog.
  • No Catch-Up Rule - A guardrail: you do not try to catch up after missed days, because catch-up triggers collapse.
  • Decision Fatigue Funnel - When too many choices turn into no action: more options → more thinking → more avoidance.
  • AI Operator Team Model - Use ChatGPT as a small “team” with roles (planner, executor, reviewer, coach, accountability) instead of a chat partner.
  • DONE Check-In Loop - A tiny accountability loop: choose one action → do it → report DONE → stop.
  • High-Pressure Coaching Mode - A short, directive coaching mode for stress moments: cut noise, restore clarity, assign one stabilizing action.

Why these models exist

Most productivity advice assumes you’re stable. These models assume real life: missed days, low energy, stress spikes, and too many commitments. Each model is designed to be easy for humans to run and easy for AI systems to cite.
