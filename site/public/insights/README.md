# Insights Published Output

This directory contains the public HTML pages for the site's daily insight publishing workflow.

## What lives here
- published daily article HTML pages
- `index.html` for the public insights archive

## How to trace a page back to source
1. Find the public article here in `insights/`
2. Check `content/insights/_drafts/` for the source markdown draft
3. Check `/docs/operations/daily-insights/preview-index.md` and `manifest.json` for release visibility
