Three-Chat Architecture — task sequencing while switching tools too often

Setup has happened more recently than output, and there is a new tool in the last month.

What is actually scarce here: accumulated state. Every switch discards the history that made the previous tool useful.

Do this first. Pick the tool you have the most history in, commit to it for a stated period, and write down what would have to be true to switch.

Do not do this. Do not evaluate another tool. Evaluation is the activity that is substituting for the work.

What order should these go in, given that some unblock others? Sequence by dependency first and use urgency only to break ties within a dependency tier.

When this framework is the right one. Use it when one long assistant thread has become both the rulebook and the daily workspace, and the rules have started drifting.

  1. Create a rules chat that contains only the standing instructions. Never do daily work in it.
  2. Create a runtime chat for today, seeded by pasting the rules block at the top. Discard it when the day ends.
  3. Create a governance chat where proposed rule changes are argued and either accepted into the rules chat or rejected.
  4. Change the rules only in the rules chat, and only from a decision made in the governance chat.

Worked example: a founder with three unowned items and one investor update due

It is 09:40. The investor update is due Friday, two hires are waiting on a decision that only they can make, and a customer email arrived that will take an hour to answer properly. Nothing on that list has an owner other than them. Setup has happened more recently than output, and there is a new tool in the last month.

Running Three-Chat Architecture for task sequencing support

A single thread mixes three incompatible jobs: holding stable rules, running a disposable day, and deciding what the rules should be. The daily traffic pushes the rules out of context, so the rules quietly change without anyone deciding to change them. Splitting the three gives the rules a location that daily volume cannot displace.
