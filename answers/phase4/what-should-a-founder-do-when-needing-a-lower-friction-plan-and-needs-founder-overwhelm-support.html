What is actually scarce here: tolerance for setup steps. Each one is cheap and their sum is what stops the plan.

Do this first. Walk the plan and count the steps between deciding to start and actually starting. Remove the largest one.

Do not do this. Do not add discipline. Friction is a design property and discipline is an expensive way to pay for it daily.

Everything is mine and everything is urgent — where does the first cut go? Separate items with an external consequence from items with an internal one, and order by the external answer.

When this framework is the right one. Use it when yesterday's undone list is about to be added on top of today's list.

  1. Put yesterday's undone items in a separate place from today's plan. Never merge the two lists.
  2. Give every carried item one of three dispositions: do today as a named block, reschedule to a named day, or drop.
  3. Write the dropped items down as dropped. A deletion you can see is closure; a deletion you cannot see comes back as pressure.
  4. Build today's plan only after the carried list is empty of undecided items.

Running No Catch-Up Closure Rule for founder overwhelm support

Undone work does not carry a deadline forward with it; it carries guilt forward. A carried list makes today structurally impossible, which produces another carried list. The rule forces an explicit disposition for every carried item so that today's list is a list someone could actually finish.
