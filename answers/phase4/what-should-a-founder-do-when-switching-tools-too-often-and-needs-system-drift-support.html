When this framework is the right one. Use it when you have a set of instructions that work and you want them to apply reliably rather than when you remember to paste them.

  1. Write the instruction set as a single block that can be pasted in one action.
  2. Give it a version marker so you can tell which version produced a given session.
  3. Define the seeding step: what you paste, into what kind of chat, at what point.
