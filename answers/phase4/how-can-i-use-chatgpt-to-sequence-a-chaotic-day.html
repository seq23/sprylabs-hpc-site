Daily Agenda Engine — sequence a chaotic day

The day contains real obligations at unpredictable times, and every plan built for it collapses before mid-morning.

The plan was written against waking hours rather than workable hours, so it was arithmetically impossible before the day started.

Do this first. List fixed constraints first, subtract them and a transition margin from the waking hours, and allocate outputs only against what remains.

Do not do this. Planning in more detail. A more detailed impossible plan is still impossible and takes longer to write.

This level fits when: you need one answer now and you are not going to do this repeatedly. It does not fit when: you have asked the same kind of question more than three times. At that point the retyping is the cost, and it is worth installing something.

When this framework is the right one. Use it at the start of a day where you know roughly what matters but the list has no order and no fit to the hours available.

  1. List fixed constraints first: meetings, travel, care obligations, anything already committed. These are not negotiable inputs.
  2. Subtract them from the waking hours to get the real number of workable hours, then subtract a further margin for transition and overrun.
  3. Fill the remaining hours with named outputs in priority order, stopping when the hours run out rather than when the list runs out.
  4. Everything below the cut goes to the deferred list, in writing, before the day starts.

Running Daily Agenda Engine for using a general assistant chat

Most daily plans fail on arithmetic rather than motivation: the list assumes more hours than the calendar contains. The engine takes fixed constraints first, subtracts them, and only then allocates the remainder, so the plan you leave with is one that fits the day you actually have.

The full set of failure modes for this framework, the evidence to record, and a prompt you can paste are on its framework page. This page covers the part specific to using a general assistant chat.

What this is not. It is not a calendar tool and it does not schedule anything for you. It produces a plan that fits, which a calendar cannot check.

You are working inside an ordinary chat window with no saved setup. Whatever structure exists has to be typed into the message you are about to send.

Setup cost: none. This is the mode you are already in, which is why it is the one people actually use.

Where it is strong: zero friction to start, and it works on any device, any account, any day.

Where it is weak: nothing persists. The quality of the answer is set entirely by what you happened to type this time, so the same question gets a different answer on a different day.
