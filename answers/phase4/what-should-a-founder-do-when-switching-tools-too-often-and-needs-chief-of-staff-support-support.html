Strategic Patience Filter — chief-of-staff support while switching tools too often

Setup has happened more recently than output, and there is a new tool in the last month.

What is actually scarce here: accumulated state. Every switch discards the history that made the previous tool useful.

Do this first. Pick the tool you have the most history in, commit to it for a stated period, and write down what would have to be true to switch.

Do not do this. Do not evaluate another tool. Evaluation is the activity that is substituting for the work.

Who turns this pile of half-formed obligations into actions? Run a conversion pass giving every item a physical next action and an owner, or routing it to a decision block.

When this framework is the right one. Use it when you are about to change direction and the current direction has not yet run long enough to produce evidence.

  1. Write down what evidence would tell you the current direction is wrong, in advance of looking for it.
  2. Check whether that evidence has actually arrived, or whether what arrived is discomfort.
  3. If the evidence has not arrived, name the date by which it would have, and hold until then.
  4. If it has arrived, pivot deliberately and write down what you learned so the next attempt starts further along.
