Executive Review Mode — avoid overplanning (0135)

The plan gets refined repeatedly and the work does not start. Each refinement feels productive and produces no output.

Planning is an activity with no failure state, which makes it a comfortable place to be when the work has one. More planning is therefore the path of least resistance and it is indistinguishable from progress from the inside.

Do this first. Cap the planning: a fixed number of minutes, then the plan is closed and the first block starts regardless of how complete it feels.

Do not do this. Making the planning step better. A better planning process is a more comfortable place to stay.

This level fits when: you want the same standard applied across sessions and you are willing to re-seed it. It does not fit when: the task genuinely needs a different standard. Forcing one mode onto everything is how modes stop meaning anything.

When this framework is the right one. Use it when you already know most of what you need to know and the problem is that it is not organized into a decision.

  1. State the decision that is actually waiting, in one sentence ending in a verb.
  2. List only what you already know that bears on it. New research is out of scope for the session.
  3. Separate the list into facts, assumptions, and unknowns, and mark which unknowns would actually change the decision.
  4. Make the decision, or name the single piece of information that would settle it and how you will get it.

Frequently asked questions

How do I tell over-planning from genuinely needing to think?

Genuine thinking changes the plan. If a planning session ends with substantially the same plan you started with, it was not thinking, and the next one will not be either.
