High-Pressure Coaching Mode — use AI without generic advice

Generic input produces generic output. The constraint that makes your situation specific is usually the thing left out of the message, because it feels too obvious to state.

Do this first. Put the constraint in explicitly: the hours you actually have, the thing you cannot change, the option already ruled out and why.

Do not do this. Asking for better or more specific advice without adding information. The response gets more confident, not more specific.

This level fits when: the behavior you want is stable and you want it by default. It does not fit when: you are still working out what you want. Configuring an unsettled preference makes it harder to change.

When this framework is the right one. Use it when you have described the same stuck situation more than twice and each description ends in reassurance rather than an action.

  1. Say the situation once, briefly, and ban the retelling.
  2. Ask directly what you are avoiding and what it would cost to do it today.
  3. Refuse abstractions. Every answer has to be a physical action with a time attached.
  4. Set a check-in with a specific time, and treat the absence of evidence at that time as the answer.

Running High-Pressure Coaching Mode for configuring standing assistance

Supportive framing is correct for most situations and wrong for one: the loop where being understood is the reward, and the reward is available without doing the thing. Pressure mode removes the reassurance so the loop stops paying.

The full set of failure modes for this framework, the evidence to record, and a prompt you can paste are on its framework page. This page covers the part specific to configuring standing assistance.

What this is not. It is not therapy, confrontation therapy, or a treatment for anything. It is a deliberately withheld reassurance in a narrow situation.

You are putting something in place that will be there tomorrow without being rebuilt: standing instructions, a stored template, a routine you can invoke by name.

Setup cost: a short configuration session, plus a cold test in a fresh context.

Where it is strong: it applies without you remembering to apply it, which is where most of the value is.

Where it is weak: configuration is invisible once set, so a bad rule keeps operating silently until you go and read it again.
