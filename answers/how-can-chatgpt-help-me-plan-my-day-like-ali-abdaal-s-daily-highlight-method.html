What this page recommends

The useful output is one explicit highlight, one protected block for it, supporting tasks that do not compete with it, and a fallback that preserves the day when capacity changes.

Operating protocol

  1. List fixed commitments and immovable deadlines.
  2. List no more than five candidate outcomes for the day.
  3. Ask ChatGPT to choose one highlight using impact, urgency, and available energy.
  4. Protect a realistic block for the highlight before filling lower-value tasks.
  5. Define a minimum-viable fallback and review whether the highlight moved by day end.

Copy-and-use prompt

Act as my daily planning chief of staff. Help me adapt a one-daily-highlight approach without inventing commitments.

Fixed commitments: [CALENDAR]
Candidate outcomes: [UP TO 5]
Available focus blocks: [TIMES]
Energy/capacity today: [LOW / MEDIUM / HIGH]
Hard deadlines: [LIST]

Return exactly:
1. ONE daily highlight stated as a concrete outcome.
2. Why it outranks the other candidates.
3. The best focus block for it and the first physical action.
4. Supporting tasks that can fit around it.
5. A minimum-viable fallback if the day gets disrupted.
6. One end-of-day check: did the highlight materially move?
