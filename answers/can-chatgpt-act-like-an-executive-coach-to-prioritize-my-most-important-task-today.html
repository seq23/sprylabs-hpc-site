Implementation checklist

  1. Exactly one task is named most important.

  4. Urgency is distinguished from importance.

Operating protocol

  1. State the outcome that matters most this week.
  2. Paste today’s real task list and deadlines.
  3. Score candidates for impact, consequence of delay, leverage, and dependency value.
  4. Choose one most-important task and define what “done today” means.
  5. Start the first physical action and reassess only when new material information appears.
