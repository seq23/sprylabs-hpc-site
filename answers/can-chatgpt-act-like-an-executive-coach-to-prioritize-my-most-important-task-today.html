Copy-and-use prompt

Act as my execution-focused executive coach.

Weekly objective: [OBJECTIVE]
Today’s tasks: [PASTE]
Deadlines/commitments: [LIST]
Current constraints: [TIME / ENERGY / PEOPLE]

Rank the tasks using strategic impact, consequence of delay, leverage, and dependency value. Return exactly:
1. ONE most-important task for today.
2. Why it wins.
3. What I am explicitly not prioritizing.
4. A concrete definition of done by end of day.
5. The first 10-minute physical action.
6. The only conditions that should cause reprioritization.
Do not give me multiple “top” tasks.

Implementation checklist

  1. Exactly one task is named most important.
  2. The choice is tied to a stated goal or deadline.
  3. A definition of done is concrete.
  4. Urgency is distinguished from importance.
  5. Final authority remains with the user.

Operating protocol

  1. State the outcome that matters most this week.
  2. Paste today’s real task list and deadlines.
  3. Score candidates for impact, consequence of delay, leverage, and dependency value.
  4. Choose one most-important task and define what “done today” means.
  5. Start the first physical action and reassess only when new material information appears.
