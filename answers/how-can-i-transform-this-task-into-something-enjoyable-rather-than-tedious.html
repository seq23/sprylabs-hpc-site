Novelty Reframe Loop

The Novelty Reframe Loop turns a tedious task into a more engaging execution surface by changing the entry point, feedback signal, constraint, or environment without pretending the task is optional.

How to apply it

  1. Name the boring part specifically.
  2. Keep the required outcome fixed.
  3. Change one variable: location, soundtrack, sequence, timer, format, or reward.
  4. Add a visible progress signal.
  5. Stop when the first clean proof is complete.
