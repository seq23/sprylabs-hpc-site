Foreground Priority Selection Rule — a student who is overwhelmed

The hardest part of the week: starting work whose deadline is far enough away to feel optional.

Do this first. Name one project as foreground for a stated period, measured in weeks rather than days.

Do not do this. Two foreground projects. Two foregrounds means the rule never fires, because every contested block is still a fresh decision.

Every item on the list feels equally urgent, which is the reliable sign that none of them is being assessed. Do not re-plan. Re-planning under overwhelm produces a longer list and a stronger sense of how much there is.

When this framework is the right one. Use it when several projects are all technically active and none of them is visibly moving.

  1. Name one project as foreground for a stated period, measured in weeks rather than days.
  2. Give every other active project an explicit background status with a maintenance floor: the minimum that keeps it from decaying.
  3. When a block is contested, the foreground project takes it. This is the entire rule and its whole value is that it is decided in advance.
  4. Review the foreground choice on a fixed date, not when a background project starts feeling urgent.
