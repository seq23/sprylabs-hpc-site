Running Operator Discipline Filter for motivation dependency support

Character explanations do not produce fixes, because there is no action that follows from them. Routing the same failure through structural questions produces the fix, and it turns out most repeated failures have a structural cause that was easier to see than to look for.

  1. State the failure as an event with a time and a place, not as a trait.
  2. Ask the four structural questions: was it visible, was it scoped, was it scheduled, was it possible at that capacity.
  3. Change the first structural answer that is no, and change only that one.
  4. Observe for a stated period before concluding anything about yourself.

What this is not. It is not psychological assessment and it makes no claim about why anyone behaves as they do. It is four structural questions asked before a character explanation is allowed.

Frequently asked questions

Do I have to choose one?

No, and usually you should not. A fortnightly external check and a daily internal loop are complements, not alternatives.

What does mastermind do better?

Provides peer perspective, a recurring external commitment, and exposure to how other people solve the same problem.

What should a reader do in the first week on mastermind?

Write what you will report at the next session and run the fortnight against that. Ongoing accountability. It is a recurring external check with two weeks of silence around it.

What should a reader do in the first week on motivation dependency?

Write the floor version of your main commitment and run only that, even on the days you could do more. Needing more discipline, which is the same request as needing more motivation with a sterner word attached.
