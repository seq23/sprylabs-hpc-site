Morning Planning

Prompt: Build a Constraint-Aware Day

Use when: the calendar is crowded or energy is uneven. Provide: fixed commitments, deadlines, energy, and available hours.

“Build today’s plan from these fixed commitments and constraints. Select one foreground output, define its finish line, and place everything else in maintenance or defer. Reject any item that is not physically executable.”

Prompt: Define the First Hour

Use when: starting friction is the main problem. Provide: the foreground output and available tools.

“Turn this output into the smallest first-hour sequence. Give me the first physical action, a 25-minute work block, and the exact evidence I should report when complete.”

Decision-Making

Prompt: Run the Arbitration Engine

Use when: several options feel equally urgent. Provide: options, deadlines, upside, downside, and dependencies.

“Compare these options using leverage, real urgency, compounding value, reversibility, and downside. Rank them, name the decision, and state what evidence would change the ranking.”

Prompt: Separate Decision From Anxiety

Use when: emotional pressure is making every option feel dangerous.

“Separate the observable facts, assumptions, emotional predictions, and reversible experiments in this decision. Do not reassure me; show me the smallest test that produces new evidence.”

Weekly Review

Prompt: Review Evidence, Not Intentions

Use when: closing the week. Provide: completed, partial, and missed outputs.

“Review this week by evidence. Identify what produced completed work, what repeatedly failed, and one operating rule to keep, change, or remove next week.”

Prompt: Detect a Repeating Pattern

Use when: the same commitment keeps slipping.

“Compare these daily logs. Identify the repeated trigger, the behavior that follows, and the system change most likely to interrupt the pattern. Do not diagnose me.”

Energy Management

Prompt: Activate a Minimum Viable Day

Use when: capacity is low but continuity matters.

“Reduce today to one meaningful action, one basic maintenance floor, and a clean shutdown. Remove catch-up work and define what counts as enough.”

Prompt: Match Task to Capacity

Use when: the planned task exceeds current attention or energy.

“Classify these tasks by cognitive load and consequence. Choose the highest-value task that fits my current capacity, then shrink it to a finishable block.”

Priority Sorting

Prompt: Choose the One Winning Move

Use when: the list is larger than the day.

“From this list, choose the one action that creates the most leverage or removes the largest future bottleneck. Explain the choice in three criteria and park the rest.”

Prompt: Cut False Urgency

Use when: every request arrives labeled urgent.

“Sort these items into real deadline, consequence of delay, dependency, and perceived pressure. Return only the items that create a real cost if not handled today.”
