Minimum viable day: choose what cannot wait

A minimum viable day is a deliberately reduced plan for a day with unusually limited capacity. It identifies necessary obligations, a feasible action and what must be deferred or renegotiated, rather than requiring an ordinary day’s output under different conditions.

Quick answer

List obligations with a consequence if left unattended today. Distinguish them from optional personal targets.

What this guide is best for: readers who need to make a concrete decision about minimum daily action.

How do you put this into practice?

Use the following sequence as a starting plan, then adjust it to the work you are responsible for.

  1. List obligations with a consequence if left unattended today. Distinguish them from optional personal targets.
  2. Check which obligation needs action, which needs coverage and which needs a message explaining the delay.
  3. Choose a small useful action within the capacity actually available, then record what the next normal review must revisit.

How do the options compare?

What would this look like in practice?

A caregiver has an unexpected appointment. They send a deadline update, arrange coverage for one necessary task and preserve a note of where the main project stands. Optional reading stays optional.
