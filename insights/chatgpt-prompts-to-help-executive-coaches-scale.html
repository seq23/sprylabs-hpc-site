Copy-and-use prompt

Act as the operations partner for my executive coaching practice. My coaching framework: [FRAMEWORK]. My typical client: [SENIORITY / INDUSTRY]. The function I want to scale today: [ONBOARDING / SESSION PREP / GOAL TRACKING / ROLEPLAY / GROUP PROGRAM / MARKETING / OPERATIONS].

Input for that function: [PASTE: intake form, session notes, goal list, conversation scenario, method outline, insight, or engagement record - anonymized]

Return exactly:
1. The draft artifact for that function (agenda, brief, goal sheet, roleplay debrief, curriculum, content set, or document).
2. The parts of it I must review or personalize before a client sees it.
3. The reusable prompt template for this function, with placeholders, so I can run it for every client.
4. One measure that tells me next month whether this saved coach-hours without lowering session quality.
Do not invent client details or claim outcomes I have not supplied.

Implementation checklist

  1. Every prompt takes the coach’s own framework and the client’s real data as input, never generic advice.
  2. Client-identifying detail is anonymized or omitted before it enters a prompt.
  3. Session preparation and goal tracking are automated; the live session judgment is not.
  4. Roleplay output is a rehearsal artifact the coach reviews, not a script the client receives.
  5. Group-program and marketing drafts are edited by the coach before any client sees them.
  6. Operations prompts produce drafts with placeholders where a contractual term is unknown.

Operating protocol

  1. Client onboarding: turn an intake form into a client profile, stated goals, constraints, and the first-session agenda.
  2. Session preparation and delivery: build a pre-session brief from the last session notes and the client’s progress report.
  3. Goal tracking: convert vague ambitions into measurable goals and generate the between-session check-in questions.
  4. Difficult-conversation roleplay: rehearse a client’s hard conversation with ChatGPT playing the counterpart, then debrief.
  5. Productized and group programs: draft the curriculum, cohort exercises, and facilitation notes from your one-to-one method.
  6. Marketing content: repurpose one anonymized coaching insight into a newsletter issue, a post series, and a talk outline.
  7. Operations: draft proposals, engagement summaries, renewal conversations, and testimonial requests from engagement records.
