Weekly review prompt: practical guide

Weekly review prompt is an instruction to compare planned work with a supplied record and produce a small set of next-week decisions.

Quick answer

Use this prompt: Compare these commitments with these results. Separate completed, blocked and dropped work. Ask about missing evidence.

What this guide is best for: readers who need to make a concrete decision about weekly review prompt.

How do you put this into practice?

Use the following sequence as a starting plan, then adjust it to the work you are responsible for.

  1. Use this prompt: Compare these commitments with these results. Separate completed, blocked and dropped work. Ask about missing evidence.
  2. Choose next-week actions after checking whether blockers need a message, a decision or a scope change.
  3. Record the action you chose, its intended result and the next occasion on which you will check it. Keep the record in a place you can return to without rebuilding your setup.

What would this look like in practice?

A freelancer provides last week’s deliverables and learns that a repeated blocker is missing client input, so the next action is a clarification request. This is an illustrative scenario, not a customer result or evidence of a measured improvement.
