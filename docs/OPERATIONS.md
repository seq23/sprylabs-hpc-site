# Operations Runbook

This repo runs as a strict execution engine.

## Primary Commands

- npm run validate:all
- npm run execution:strict
- npm run reddit:daily
- npm run reddit:evening
- npm run admin:build

## Health Standard

The repo is healthy only when all of these are true:

- CANNIBALIZATION CONTRACT PASS
- QUERY COVERAGE PASS
- validate_fanout_warning: OK
- PAGE TYPE CONVERSION FLOOR PASS: warnings=0
- [validate_all] OK

## Normal Operator Flow

1. Pull latest main.
2. Run npm run validate:all.
3. If needed, run npm run execution:strict.
4. Do not manually edit generated pages unless explicitly instructed.
5. Commit only intentional changes.
6. Push to main.
7. Confirm GitHub Actions are green.

## Do Not Touch Without Owner Approval

- scripts/validators/
- scripts/execution/
- scripts/intake/build_backlog_full_coverage.js
- data/scoring/cannibalization_map.json
- .github/workflows/

npm run admin:build

process.env.SPRY_ADMIN_PASSWORD || "aplayer"
