# Citation Dominance Operating Model

**Status:** Active
**Reviewed:** 2026-06-20
**Goal:** Increase qualified LLM citations and purchase-path visibility toward 100,000 citations per month for the BHPC/Spry property cluster.

## Governing rule

The goal is fixed. The implementation is adapted to this repository. The repo does not manufacture credentials, thin pages, unsupported outcome claims, or external authority. It uses the existing query registry, manual-expansion source model, citation schema, programmatic admission, workflow governance, and distribution pipeline.

## Four implemented layers

1. **Substrate:** query, framework, source, author, page-admission, and agent-run registries.
2. **Reference pages:** one canonical page per primary query with a definition, extraction block, visible author, review date, source basis, artifact, and product bridge.
3. **Authority:** real creator and publisher identity, public editorial methodology, official or primary sources, explicit limitations, and human escalation. No credentials or outcomes are invented.
4. **Distribution:** server-rendered HTML, stable URLs, robots access, sitemaps, `llms.txt`, `llms-full.txt`, IndexNow artifacts, and a GSC/Bing submission manifest.

## June 20, 2026 monitor response

The four weak pages are source-governed manual expansions. The three discovered queries have dedicated canonical pages. Search submission artifacts include every changed priority URL.

## Measurement law

A monitor run less than 72 hours after deployment is **diagnostic**, not a final performance verdict. It may verify that pages exist and expose content gaps, but it is too early to infer whether search engines and LLM retrieval systems have recrawled, indexed, cached, ranked, or cited the release. Compare citation outcomes after at least 72 hours and preferably on a seven-day cadence.

## Search engine handoff

After deployment:

- verify both domain properties and sitemaps in Google Search Console;
- inspect and request indexing for the changed priority URLs only;
- verify both sites and sitemaps in Bing Webmaster Tools;
- submit the prepared priority URL file through IndexNow;
- record submission evidence without claiming indexing or citation until observed.
