## Goal

Move the BHPC / APlayerMode property cluster toward 100,000 qualified LLM citations or surfacings per month by building the four-layer citation stack and the Phase 1–4 execution roadmap inside the repository.

## Four-layer implementation

### Layer 1 — Substrate

This repo uses methodology definitions, framework taxonomy, author identity, source basis, outcome-pattern records, and citation registries as the raw verified substrate. It does not invent professional credentials, client results, press, podcast appearances, or academic authority.

Implemented artifacts:

- `data/citation/citable_pages.json`
- `data/citation/query_registry.json`
- `data/citation/framework_registry.json`
- `data/citation/methodology_taxonomy.json`
- `data/citation/outcome_pattern_registry.json`
- `data/entities/author_profile.json`
- `data/entities/authority_signal_manifest.json`
- `data/research/ai_coaching_source_registry.json`

### Layer 2 — Reference pages

This repo now includes dedicated reference pages for the APlayerMode / BHPC strategy shape:

- `/methods/{framework}/`
- `/vs/{competitor}/`
- `/glossary/{term}/`
- `/case-studies/{scenario}/`
- existing `/answers/`, `/insights/`, `/comparisons/`, and priority citation pages

Each new phase page is server-rendered HTML with a stable URL, canonical tag, one-sentence definition near the top, product bridge, reviewed date, and JSON-LD.

### Layer 3 — Authority signals

The authority layer is intentionally truth-bound. It includes named author and publisher records, methodology documentation, review cadence, source registry, sameAs fields where actually known, and explicit anti-fabrication boundaries.

Pending or external signals such as podcasts, press, Wikidata, Wikipedia, and academic citations are represented as roadmap items, not claimed as completed facts.

### Layer 4 — Distribution and retrieval

The distribution layer includes robots access, sitemaps, `llms.txt`, `llms-full.txt`, IndexNow prep, search submission manifest, stable server-rendered HTML, and a syndication plan for future YouTube transcripts, guest essays, authentic community participation, and co-citation work.
