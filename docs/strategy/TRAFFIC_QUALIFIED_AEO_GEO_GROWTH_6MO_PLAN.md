## Strategy upgrade

The repo no longer treats page volume as the core win. The governing strategy is traffic-qualified authority growth:

1. collect source-compliant demand signals;
2. normalize them into AEO/GEO/SEO opportunity records;
3. cluster and score them by executive-performance demand, authority fit, and risk;
4. convert them into release candidates;
5. produce a release plan that selects only useful create/repair/atom/link/schema actions;
6. emit a proof packet with external telemetry explicitly marked absent unless actually present.
