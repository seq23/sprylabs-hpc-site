60-Second Procedure (Use This Today)

  • Name the day state (low / normal / high).
  • Pick ONE objective only.
  • Cap scope (20–30 minutes).
  • Start immediately (no research, no re-planning).
  • Report DONE.
  • Stop. Do not add more to ‘prove’ anything.
