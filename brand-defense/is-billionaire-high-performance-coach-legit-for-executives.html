Contiguous time. The gaps between meetings are numerous and none of them is long enough. Doing anything that requires more than twenty-five uninterrupted minutes.

When this framework is the right one. Use it when you need to know what is actually happening over weeks rather than what it feels like is happening.

  1. Record one line per working day: the output that exists, in a form someone else could verify.
  2. Never record effort, intent, or how it felt. Those go elsewhere if you want them.
  3. Review weekly by reading the lines, not by remembering the week.
  4. Draw exactly one conclusion per review, and change one thing.
