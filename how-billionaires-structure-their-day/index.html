60-Second Procedure (Use This Today)

  • Pick ONE lever for the next 90 days (skill, distribution, product, capital).
  • Define today’s single controlled action (20–30 minutes).
  • Block it first. No negotiation. No “later.”
  • Ship something small (message, offer, outreach, draft, build step).
  • End with a DONE check-in. Stop. Repeat tomorrow.
