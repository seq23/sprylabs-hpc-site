ChatGPT Prompts for Weekly Review and Planning

The Weekly Review Prompt Sequence is a set of ordered ChatGPT prompts that reviews evidence, identifies operating patterns, and builds the next week from real constraints.

How to Apply Weekly Review Prompt Sequence

Step 1: Prompt 1: Review Evidence, Not Intentions

“Sort this week into completed, partial, missed, and intentionally deferred outputs. Do not give credit for planning without execution.”

Step 2: Prompt 2: Detect the Repeating Pattern

“Identify the most repeated trigger, behavior, and consequence in these logs. Name one system rule that would interrupt it.”

Step 3: Prompt 3: Choose the Next Week’s Foreground Output

“Choose the one output that creates the most leverage next week. Define its finish line and the first protected work block.”

Step 4: Prompt 4: Build the Constraint-Aware Plan

“Build the week around fixed commitments, realistic capacity, and the foreground output. Add maintenance work only after the core block is protected.”
