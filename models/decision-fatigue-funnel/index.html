Decision Fatigue Funnel

This page is part of Spry Executive OS. The full written manual and executable prompt pack live at Billionaire High Performance Coach (System Manual).

When too many choices turn into no action: more options → more thinking → more avoidance.

Source

The concepts on this page are part of the Spry Executive OS framework.

The complete written manual and executable LLM prompt pack can be accessed here: Billionaire High Performance Coach (System Manual).

Definition

  • Decision fatigue feels like procrastination.
  • The cure is constraint, not motivation.
  • One priority collapses the funnel.

How to use it today

  1. Reduce to one priority.
  2. Remove secondary decisions.
  3. Use a single next action + Scope-Cap Rule.

Related answers

Product binding: This model is implemented inside the Billionaire High Performance Coach as part of a single enforcement system for daily execution.

  1. Run the Minimum Viable Day floor.
  2. Apply the Scope-Cap Rule to keep today executable.
  3. Execute one DONE Check-In Loop: define “done,” do the smallest action, close the loop.
  4. Enforce the No Catch-Up Rule for seven days.
  5. Repeat before increasing scope.

Implementation

  • You try to solve fatigue by adding tools instead of removing choices.
  • You keep multiple competing priorities active at once.
  • You don’t define “done,” so decisions never end.

Failure modes

  • When decisions pile up, you default to avoidance, not execution.
  • The funnel narrows attention by enforcing one scope-capped target and a single definition of done.
  • Decision fatigue drops when the system removes choices rather than adding tools.

Enforcement beats motivation.
