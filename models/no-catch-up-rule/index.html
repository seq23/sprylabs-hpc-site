Definition

  • Catch-up creates unrealistic load.
  • Unrealistic load creates failure.
  • Failure restarts the reset cycle.

How to use it today

  1. After a miss, reduce scope.
  2. Do today only.
  3. Let the backlog wait until stability returns.

Implementation

  • You measure success by backlog reduction instead of continuity.
  • You use guilt as scheduling input.

Failure modes

  • Catch-up multiplies tasks, increases pressure, and triggers avoidance-then resets the cycle again.
  • Forbidding catch-up keeps the system stable and prevents backlog-based shame spirals.
  • No Catch-Up Rule protects the floor: today stays doable.
