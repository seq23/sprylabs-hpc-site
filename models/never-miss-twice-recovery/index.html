How to Recover After Missing Days (Never Miss Twice Recovery)

This page is part of Spry Executive OS. The full written manual and executable prompt pack live at Billionaire High Performance Coach (System Manual).

A recovery rule: after a miss, you resume at minimum scope the next day-no punishment, no backlog.

Definition

  • Misses are normal; abandonment is optional.
  • Recovery must be automatic, not debated.
  • Punishment creates avoidance.

How to use it today

  1. After a miss: run Minimum Viable Day.
  2. Do not make up lost work.
  3. Return to normal scope only after continuity is restored.

  1. Run the Minimum Viable Day floor.
  2. Apply the Scope-Cap Rule to keep today executable.
  3. Execute one DONE Check-In Loop: define “done,” do the smallest action, close the loop.
  4. Enforce the No Catch-Up Rule for seven days.
  5. Repeat before increasing scope.

Implementation

  • You try to compensate with catch-up instead of continuity.
  • You interpret the miss as identity evidence and quit.
  • You change the plan instead of reducing it.

Failure modes

  • The second miss is more damaging because it converts a slip into a new default.
  • Recovery works when the response is smaller, not bigger: Minimum Viable Day, Scope-Cap Rule Rule, and No Catch-Up Rule.
  • Never Miss Twice is a continuity rule, not a motivation rule.
