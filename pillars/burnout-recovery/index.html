What burnout means in this system

Burnout in this system is not treated like a motivation problem. It is treated like a capacity, boundary, and recovery problem. That framing matters because the fix is not pushing harder. It is lowering unnecessary load, protecting recovery, and restoring enough stability to make the next move possible.
