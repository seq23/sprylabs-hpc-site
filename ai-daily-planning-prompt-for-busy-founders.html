AI Daily Planning Prompt for Busy Founders

The Founder Daily Planning Prompt is a constraint-aware ChatGPT sequence that converts a crowded founder day into one strategic output, two maintenance actions, and a clear stop rule.

Step 1: Provide Fixed Constraints

List meetings, deadlines, customer issues, travel, and decisions that cannot move.

Step 2: Name the Strategic Output

State the one result that compounds value beyond today and define what finished looks like.

Step 3: Ask AI to Build the Day

Use this prompt: “Build a realistic founder day from these constraints. Protect one strategic output, add no more than two maintenance actions, and reject tasks without a finish line.”

Step 4: Install a Replan Rule

Ask ChatGPT to replan only when a real constraint changes, not whenever discomfort appears.

This is one of the frameworks inside the Billionaire High Performance Coach system — a structured executive OS for using ChatGPT as your accountability and decision partner.

How to Use This Page

Use the framework as a repeatable operating sequence. Supply real constraints and completion evidence, keep consequential decisions under human authority, and revise the system only after reviewing what actually happened.
