ADHD Prompt Stack

A prompt is useful only when it has a defined use case, input contract, output contract, and safety boundary. These prompts organize work; they do not diagnose ADHD or decide medical care.

  • Use the Task Start prompt when the work feels too large to enter.
  • Use the Overwhelm prompt when several obligations compete for attention.
  • Use the Day Plan prompt when calendar limits and energy must shape the work.
  • Use the Return prompt immediately after distraction or interruption.
  • Use the Closure prompt to record evidence and prepare the next start.

ADHD Prompt Library

Task start

Turn this outcome into one visible finish line and the first physical action that takes under two minutes. Ask one clarifying question only if the result cannot be observed.

Overwhelm

Sort these obligations into fixed, high-consequence, deferrable, and optional. Choose one foreground output and explain what is deliberately not happening today.

Daily planning

Build a realistic plan from this calendar, available energy, and deadlines. Include transition buffers and no more than one major output.

Distraction recovery

Using this last known state, tell me the smallest valid action that resumes the task. Do not redesign the whole plan.

End-of-day closure

Classify these outputs as complete, partial, or open. Capture the next action for every open loop and prepare one starting cue for tomorrow.

Why This Framework Works

The framework reduces hidden decisions and turns an abstract goal into observable actions, evidence, and review. It also makes failure diagnosable: the reader can see whether the problem was task clarity, capacity, environment, timing, authority, or the absence of a recovery rule.

Use the framework as a bounded experiment. Keep the first version small enough to run under ordinary conditions, record what actually happened, and change one operating variable at a time instead of replacing the entire system.

Worked Example: Recovering from a derailed afternoon

The user pastes the last known state of a proposal and the remaining 30 minutes. The Return prompt produces “add the missing pricing assumption and save the draft,” rather than rebuilding the entire afternoon.

What to measure: Did the framework produce a clearer decision, a completed action, a shorter recovery time, or a better handoff? Record the observable outcome rather than whether the process felt impressive.

Frequently Asked Questions

What should I do first?

Use the smallest step in the framework that produces new evidence or restores motion. Do not begin by redesigning the entire system.

What if the framework fails on a difficult day?

Use the minimum valid version, record where the breakdown occurred, and change one constraint at the next review. Do not create catch-up punishment.

No. It provides educational and organizational support only. Diagnosis and treatment belong to qualified professionals.
